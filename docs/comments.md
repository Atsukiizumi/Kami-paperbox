# 代码注释约定

纸匣的注释要能回答三件事，而不是复述下一行代码在干什么：

1. **作用**：这个文件/函数负责哪一块。
2. **用法**：从哪里调用、传入什么、不要从哪里 import。
3. **为什么**：为什么选这种实现（访客 Cookie、跨列留洞、SQLite 存字而原图存文件、不用图数据库……）。

## 写在哪

- **文件头**（`src/lib/*`、关键组件和 API 路由）：三段式，中文，几行即可。
- **函数**：只有「非显而易见的取舍」才写。例如为什么 FANBOX 要回转 `/auth/start`，不要写 `// 把 i 加一`。
- **不要**：给 `ui/` 零件、测试、生成文件（`routeTree.gen.ts`）堆注释。

## 模板

```ts
/**
 * 一句话名字。
 *
 * 作用：……
 * 用法：……
 * 为什么：……
 */
```

改行为时把对应的「为什么」一起改，避免注释说的是上一个实现。
