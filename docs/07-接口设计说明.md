# 07 — 接口设计说明

> 基线 `main@75e7de0`（含 bd1f28c）。本站 12 路由 + 上游接口清单 + 设计评价。

## 7.1 本站 API（全部 `runtime=nodejs` + `force-dynamic`；壳在 app/api，实现在 src/routes/api）

鉴权：`withDataPlane`（next-route.ts:22-48）= Fetch-Metadata 同站校验 → 应用会话 / guest 标记 / LAN 令牌三态。

## 7.3 设计评价

- **一致性**：全部 JSON、统一 `{ok:...}` 或错误 `{error}`；错误二分 502/400 语义清晰（S7）。DTO 即 zod 推断类型，前后端同源（source.ts 双端 import）。
- **RESTful**：不追求 REST（RPC 风格 op 判别联合）——对内部单客户端是**正确取舍**；vault 四方法除外。
- **版本控制**：无 /api/v2（单客户端同仓演进，无版本需求）。
- **重复接口**：无；whoami 无 zod 是唯一校验缺口。
- **安全**：见 12 号；超时/重试语义见 04；幂等：sync/vault/rankings 均 UPSERT 幂等，媒体层天然幂等。
- **改进项**：whoami 无 zod（唯一校验缺口）；SEC-14 legacy 明文写路径待关；其余（TD-20 guest 决策 / SEC-11 rateLimit / SEC-12 同站校验）已于 bd1f28c 清偿。
