# 04 — 业务流程说明（含调用链）

> 基线 `main@75e7de0`（含 bd1f28c）。流程图见 [核心业务流程图](diagrams/核心业务流程图.md)，时序见 [时序图](diagrams/时序图.md)，状态机见 [状态图](diagrams/状态图.md)。每条流程给出：触发/前置/输入/处理/异常分支/数据与状态变化/输出/回滚。

## 4.1 浏览取数（首页三源 feed）

- **触发**：进入 `/`、切站/切 feed、翻页、强制刷新。**前置**：水合门 `useSettingsHydrated()` 为 true（SSR 恒 false，防错位）。
- **调用链**：`routes/index.tsx useInfiniteQuery` → `fetchSource`（source.ts:139，POST /api/source）→ `withDataPlane` 闸 → `routes/api/source.ts` → `cachedDispatchFetch`（source-cache.server.ts:129）→ `unstable_cache` 二层 → `dispatchFetch`（upstream/dispatch.ts:20）→ 站点适配（pixiv.ts/fanbox.ts/booru-sites.ts）→ `upstreamJson`/`booruJson` → `outboundFetch`（undici 池→curl 降级）→ 上游。
- **分支**：盘缓存命中（30min 内，键=op 参数+safeMode/hideAi+账号 id 或 guest）直接返回；`fresh:true` 跳读仍写回 + `revalidateTag` 立即失效 Next 层；Pixiv 日榜「未公布窗口」404/空列表 → 回落昨天 → 再回落无日期（pixiv.ts:110-149）；需要登录的 feed（R-18 榜/推荐/关注）无凭据 → 400 用户态错误。
- **数据变化**：浏览成功第一页（booru）→ PUT /api/rankings 落快照；卡片进入浏览缓存（localStorage 24h）。
- **异常**：UpstreamError→502、其余→400（classifySourceError）；客户端 Alert 展示 message。**回滚**：无服务端状态需回滚；缓存写失败按 miss 自愈。
- **输出**：WorkCard[]（统一卡片模型，含 nsfw/ai 标记）。

## 4.2 媒体加载（封面/详情图）

- **调用链**：`ProxiedImg`（预热带 ±800px、退避 4 次）→ `acquireMediaLane`（浏览器 4 车道，priority 插队）→ `GET /api/media?u=` → 闸 → `fetchMediaResponse`（media.ts:104）→ 白名单校验 → 盘缓存（sha256(url)）→ `withMediaGate`（服务端并发闸）→ 出站（pximg 带 Referer、danbooru 走 curl+Basic、fanbox 带 cookie）→ 魔数嗅探 → `rememberMedia` 落盘。
- **异常分支**：429/503 指数退避重试（throttle.mediaRetry）；404 透传；>48MB → 413 / 流式断流；abort → 204；单飞共享请求被首调用方 abort → 各自重拉一次。
- **缓存策略**：出站头 `max-age=604800, immutable`；fanbox.cc/搜图引擎域名不落盘；>8MB 不落盘（PER-8）。
- **回滚**：无需；水位超限（media 2GB/source 512MB，每 50 写扫描）按 mtime 淘汰至 80%。

## 4.3 收入纸匣 + 下载队列

- **触发**：卡片「收进纸匣」/「入队」、详情页、合集页整包。
- **调用链（收藏）**：collectWorkFiles（save-work.ts:19-81；ugoira：拉 zip→unzipUgoira→encodeUgoiraGif，编码失败回退存原 zip）→ saveVaultWork（IndexedDB 立即可见）→（可选）writeRelativeFile 用户文件夹镜像 →（未落文件夹时）pushVaultToServer → PUT /api/vault（multipart meta+页）→ vault-store put 原子协议：全部页先写 `.{n}.tmp` → `BEGIN IMMEDIATE` 事务（删旧 pages 行/插新行/upsert works）→ COMMIT → rename → 清未引用旧文件。
- **调用链（下载）**：enqueueWork → useQueue（≤80 条、去重）→ runQueue（Web Locks 唯一执行者）→ fetchBlob（90s 硬超时，TD-29）→ 用户文件夹/下载。
- **状态机**：队列项 pending→running→done | failed→(retryable? 退避 4/8/16s ×3)→failed-final | canceled（见状态图）。
- **异常与回滚**：任何时点崩溃 SQLite 自洽（事务）；文件层最差个别页 miss，重收自愈；浏览器 IDB 与服务端目录最终一致（无冲突检测，后者覆盖）。

## 4.4 图站登录（浏览器中转）

- **触发**：设置页/向导点「投屏登录」。**前置**：puppeteer-core + 系统 Chrome/Chromium。
- **调用链**：SessionRelay POST `{site}` → browser-login.server 启无头 Chrome（--no-sandbox，走用户代理）→ CDP screencast 帧回传（轮询响应**剥离凭据**）→ 用户事件经 `{action:"input"}` 转发 → 循环 readCookies 直至 PHPSESSID 匹配 `^\d{1,12}_[A-Za-z0-9._-]{8,}$`（访客串被 sanitizePixivCookie 丢弃）→ done → 前端 `?credentials=1` 一次性取走（内存即清）→ applyLoginSession 写 store + syncSessions 落三枚 HttpOnly cookie。
- **异常**：4 分钟超时；job 单例互顶；非 2xx（含访客 401）**快速失败**并给出「需要先登录应用账号」或网关错误文案（bd1f28c，不再无限轮询）。
- **回滚**：`{action:"cancel"}` 或超时 → job 清理；凭据未取走则随 job 销毁。

## 4.5 账号同步（推送/拉取）

- **推送**：AccountSyncBridge 监听 5 个 store → 4s 防抖 → pushAccountSyncSegment：有 KEK → settings 段 sealJson 密文；无 KEK → plain + credsOmitted（7 个凭据字段置空）；「无 KEK 且远端是密文」→ 跳推。POST /api/account/sync（requireUserId）→ UPSERT user_sync_segments → scheduleSnapshotDump。
- **拉取**：登录时 ensureSyncKek（密码 + 服务端固定 kdf_salt 派生，raw key 只存 sessionStorage）→ GET → 逐段 LWW 比较 exportedAt → cipher+无 KEK 跳过 / cipher+有 KEK 解密后**凭据子字段本地非空保留**（脏标记 `kami-cred-dirty-v1` + mergeCredentialsOnPull，合并发生时补推 settings，bd1f28c）/ plain+credsOmitted 回填本地凭据。
- **异常**：时钟偏移 → 旧盖新或永不应用（无版本向量）；legacy 整份过渡路径仍接受明文 settings 落库（SEC-14/TD-25）。

## 4.6 反向搜索

- **调用链**：拖放/粘贴 → prepareSearchImage（最长边 768px JPEG q0.82，≤250KB 跳过）→ POST /api/reverse-search（≤8MB、MIME 白名单）→ 单引擎或三引擎 `Promise.all` → 各引擎 session/双跳解析（ascii2d 色+特征两路去重合并）→ 结果 URL 映射回本站作品（workFromUrl）。
- **限流**：每引擎全局间隔预约（saucenao 8s / ascii2d 15s / iqdb 6s；有 key 压 2.5s）；等待 >12s 抛错建议换 IQDB；bot 挑战页识别归类。
- **异常**：单引擎失败/限额不影响其他组（status: error/limited）。

## 4.7 榜单归档（booru）

浏览 booru 榜第一页成功 → rememberRanking PUT /api/rankings（site 限 booru、items 截 200）→ SQLite snapshots upsert（id=`site:period:date`）。管理页 GET/DELETE。无 TTL 无上限（TD-31）。异常：store 打开失败 → health=unavailable，接口 503，前端继续用即时数据。
