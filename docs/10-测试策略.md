## 10.2 覆盖评估

- **强**：上游解析（最脆面有固定样本兜底）、崩溃安全协议（vault/快照有回归）、安全纯函数、跨端脚本（with-app-env 17 例）。
- **弱**：UI 层零测试（乐观更新类 bug 如 TD-23 正是漏网之鱼——该例已修，家族风险仍在，防线靠 M9 组件测试）；E2E 依赖真实上游（抖动红，CI 已有软通过但覆盖打折）；无覆盖率数字，盲区不可见。
- **已知坑**：本地 e2e `reuseExistingServer:!CI` 复用普通 dev server 时数据隔离失效（TD-26）。

## 10.4 新增测试的落点约定

纯函数同目录 `.test.ts`；server 模块用 `.server.test.ts`（db.ts 在 node:test 下跳过真实 .data 引导）；策略/时序类抽 plan 纯模块（先例：sign-out-plan、migration-plan、queue-retry）；E2E 数据必须经 e2e-server.mjs 隔离根。
