## 已定参数与边界

- 沿用墨黑书案、宣纸、既有字体和纸感控件；使用现有 CSS / WAAPI，无新动画库。
- 按下 80ms、松开 150ms；hover 150ms，轻抬 2–3px；普通浮层展开 220ms、收起 150ms；网格重排、预览和灯箱展开 250ms；图片淡入 150ms；飞纸 400ms。
- 曲线沿用 `cubic-bezier(0.22, 1, 0.36, 1)`；复用现有 token，只允许局部 ±30ms 的观感校准。
- left/top/width/height 只用于设置最终几何，禁止逐帧补间；不同用途的 transform 分层，结束后清理临时样式与 will-change。
- 动效偏好沿用应用内 `motionEnabled` / `html[data-motion]`，不改为跟随系统。关闭动画只结束补间：`open=true` 的灯箱保持可见，`open=false` 才卸载。
- 只管理自己创建的 UI 动画；不暂停 GIF/Ugoira 内容，不全局取消其他组件动画，不让动画阻塞业务操作。
- 保留浏览挂载、返回位置、预热、媒体车道、重试、队列和持久化语义。飞纸仅表示「已入队」，不能提前显示收藏或下载完成。
- 本轮不增加跨路由共享元素转场、惯性滚动、3D 翻页、新业务功能或存储迁移。
