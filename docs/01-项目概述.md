## 1.2 项目目录结构

```text
kami-paperbox/
├── app/                     # Next.js App Router：全部是薄壳（页面 re-export src/routes/*，API re-export src/routes/api/*）
│   ├── page.tsx … settings/ # 11 个页面路由
│   └── api/                 # 13 个 API Route Handler（source/media/social/vault/…）
├── src/
│   ├── routes/              # 真正的页面组件与 API 实现（保留 TanStack 风格文件名，如 work.$source.$id.tsx）
│   ├── components/          # 业务组件 + ui/（shadcn 风格基础组件）
│   ├── lib/                 # 核心逻辑（~100 个文件，模块设计见 05 文档）
│   │   ├── auth/            # Better Auth 配置、会话、Gate 身份、隔离
│   │   ├── app-data/        # Grok connectors 网关客户端（本项目未用的外部数据通道）
│   │   ├── multiplayer/     # WebRTC P2P 房间库（模板遗留，无消费者）
│   │   └── data/            # booru-database.json 中文标签库（~119KB，随包发布）
│   └── styles.css           # Tailwind 4 + 纸感设计系统（816 行）
├── migrations/              # SQL 迁移：0001_auth.sql（Better Auth 表）、0002_user_sync.sql；auth/ 子目录为模板副本（不参与执行）
├── server/middleware/       # Nitro 平台中间件（grok-pwa / swallow-abort）——Next 迁移后为死代码
├── scripts/                 # 构建/QA/迁移/打包脚本（with-app-env、browser-smoke、qa-*、migrate 等，含单测）
├── docs/                    # 项目文档（本套 + 专题文档）
├── public/                  # 品牌资产（og.jpg、x-banner.jpg、favicon.svg）+ __grok/ 平台资产
├── .data/                   # 运行时数据（gitignore）：media/source 缓存、vault/、rankings/、快照、代理配置
├── .grok/                   # Grok App Builder 沙箱配置（app-env.json：VITE_AUTH_ENABLED）
├── Dockerfile / docker-compose.yml
├── kami.config.json         # 本机运行配置（host/port/proxy/throttle，gitignore）
└── startup.sh               # Grok 沙箱容器重启入口（本机开发不使用）
```

历史脉络（git log + 产物佐证）：项目诞生于 **Grok App Builder 模板（Vite + TanStack Start + Nitro）**，0.8.56（2026-09-08）迁移到 **Next.js 15 App Router** 并删除 Vite 退路（CHANGELOG「去掉 Vite / TanStack Start 退路」）。仓库因此同时存在三代痕迹：Grok 沙箱工具链（部分失效）、Next 现行链路、Nitro/Vercel 遗留产物（`.vercel/output`、`server/middleware`、pnpm-workspace 的 nf3 override）。

## 1.5 项目依赖关系

**项目间依赖**：单体仓库，无 workspace 子项目（pnpm-workspace.yaml 仅剩 nf3 override，属遗留）。

**第三方依赖分组**：

- 框架：next、react/react-dom、typescript、tailwindcss、lightningcss
- UI：@radix-ui/*（17 个）、lucide-react、sonner、vaul、cmdk、react-resizable-panels
- 状态/数据：zustand、@tanstack/react-query、zod、react-hook-form、@hookform/resolvers
- 服务端：@electric-sql/pglite、pg、kysely、better-auth、jose、undici、puppeteer-core
- 媒体：fflate、gifenc
- **已核实未使用**：`recharts`（grep 全仓库零引用）、`react-day-picker`、`date-fns`【基于源码推导，shadcn 模板连带安装】
- 遗留：`nf3` override（Nitro 打包器，Next 时代无意义）

**外部系统依赖**（运行时）：

| 外部系统 | 用途 | 失败影响 |
| --- | --- | --- |
| Pixiv（www.pixiv.net） | 榜单/搜索/详情/社交/动图 | 该站功能不可用 |
| FANBOX（api.fanbox.cc） | 创作者页/帖子/付费内容 | 需 FANBOXSESSID 的功能不可用 |
| yande.re / konachan.com(.net) / danbooru.donmai.us | 图站列表/榜单/合集 | 单站不可用；konachan 有镜像回退，danbooru 有账号通道 |
| SauceNAO / ascii2d / IQDB | 以图搜图 | 单引擎降级，其余继续 |
| gate.grok.me / auth.grok.me | 部署态应用登录（JWT/OAuth） | 本机形态不依赖 |
| connectors.grok.me | app-data 外部数据网关 | 本项目未消费 |
| 本机 Chrome/Chromium + curl 可执行文件 | 登录中转、代理兜底 | 登录中转/兜底降级 |
