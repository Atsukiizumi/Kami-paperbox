## 1.2 项目目录结构

```text
kami-paperbox/
├── app/                     # Next.js App Router：全部是薄壳（页面 re-export src/routes/*，API re-export src/routes/api/*）
│   ├── page.tsx … settings/ # 11 个页面路由
│   └── api/                 # 13 个 API Route Handler（source/media/social/vault/…，withDataPlane 包装）
├── src/
│   ├── routes/              # 真正的页面组件与 API 实现（保留 TanStack 风格文件名，如 work.$source.$id.tsx）
│   ├── components/          # 业务组件 + ui/（shadcn 风格基础组件）
│   ├── lib/                 # 核心逻辑（~150 个文件，模块设计见 05 文档）
│   │   ├── auth/            # Better Auth 配置、数据面访问闸、LAN 令牌、隔离
│   │   ├── upstream/        # 上游适配（TD-01 拆分：pixiv/fanbox/booru-sites/media/dispatch/http）
│   │   └── data/            # booru-database.json 中文标签库（~119KB，随包发布）
│   └── styles.css           # Tailwind 4 + 纸感设计系统
├── migrations/              # SQL 迁移：0001_auth.sql、0002_user_sync.sql、0003_user_sync_segments.sql；auth/ 子目录为模板副本（不参与执行）
├── scripts/                 # 构建/QA/迁移/打包脚本（with-app-env、qa-*、migrate 等，含单测）
├── docs/                    # 项目文档（本套 + 专题文档）
├── public/                  # 品牌资产（og.jpg、x-banner.jpg、favicon.svg；__grok/ 已随平台退出删除）
├── .data/                   # 运行时数据（gitignore）：media/source 缓存、vault/、rankings/、快照、代理配置、auth-secret.json
├── .grok/                   # 沙箱时代环境注入残留（app-env.json：VITE_AUTH_ENABLED；R-06 脱钩后待清理）
├── .github/workflows/       # ci.yml（typecheck + test + lint + build 四门禁）
├── Dockerfile / docker-compose.yml
├── kami.config.json         # 本机运行配置（host/port/proxy/throttle，gitignore）
└── startup.sh               # 沙箱容器重启入口（本机开发不使用）
```

历史脉络（git log + 产物佐证）：项目诞生于 **Grok App Builder 模板（Vite + TanStack Start + Nitro）**，0.8.56（2026-09-08）迁移到 **Next.js 15 App Router** 并删除 Vite 退路；2026-09-10 **Grok 平台完全退出**（TD-04/R-06：`server/`、`public/__grok/`、平台脚本、品牌注入、OAuth 联邦与 Gate JWT 全删，`.vercel/` 产物仍在但不再维护）。当前仓库只剩 Next 现行链路与少量 `.grok/`、`startup.sh`、`.vercel/` 残留。

## 1.5 项目依赖关系

**项目间依赖**：单体仓库，无 workspace 子项目（pnpm-workspace.yaml 已随 TD-04 删除）。

**第三方依赖分组**：

- 框架：next、react/react-dom、typescript、tailwindcss、lightningcss
- UI：@radix-ui/*（20 个）、lucide-react、sonner
- 状态/数据：zustand、@tanstack/react-query、zod、react-hook-form、@hookform/resolvers
- 服务端：@electric-sql/pglite、pg、kysely、better-auth、undici、puppeteer-core
- 媒体：fflate、gifenc
- **已核实零引用（TD-15 残余，待删）**：`cmdk`、`vaul`、`react-resizable-panels`、`jose`（Grok 退出后 JWT 验证已无调用方）——2026-09-11 复核 grep 全仓库零 import
- 已清理：recharts / react-day-picker / date-fns（TD-15，commit 15f8ed7）

**外部系统依赖**（运行时）：
