## 1.2 目录结构（核心目录与职责）

```text
kami-paperbox/
├── app/                    # Next.js App Router 薄壳层
│   ├── api/*/route.ts      #   12 个 API 路由壳：re-export src/routes/api/* + withDataPlane 包装
│   ├── */page.tsx          #   11 个页面壳：re-export src/routes/* 实现
│   ├── layout.tsx          #   唯一 server 组件（文档骨架 + 主题防 FOUC 内联脚本）
│   └── providers.tsx       #   Provider 嵌套树（Auth > Query > Theme > Tooltip > 壳组件）
├── src/
│   ├── routes/             # 页面与 API 处理器真实实现（TanStack 风格命名，如 work.$source.$id.tsx）
│   │   └── api/*.ts        #   10 个 API 处理器（zod 校验、错误分类）
│   ├── components/         # 60+ UI 组件（app-shell/masonry-board/artwork-card/... + ui/* 基件）
│   ├── lib/                # 全部业务与基础设施模块（平铺 ~150 文件，.server.ts 后缀 = 服务端专属）
│   │   ├── upstream/       #   上游适配层（pixiv/fanbox/booru-sites/media/dispatch/http）
│   │   ├── auth/           #   better-auth 配置 + PGlite 方言 + LAN 令牌 + 数据面闸
│   │   └── data/           #   打包的 booru 标签库（1,104 条 en→zh）
│   └── styles.css          # Tailwind v4 @theme token + 5 主题 × 明暗 + masonry 兜底
├── migrations/             # Postgres/PGlite SQL 迁移（0001 auth、0002/0003 同步分段；auth/ 子目录为 opt-in 模板）
├── scripts/                # 14 个工具脚本（环境包装/迁移/e2e server/QA×4/打包）+ 3 组单测
├── e2e/                    # Playwright 三条规格（关键路径/浏览缓存/访客层）
├── data/booru-database/    # 标签库源数据（README）
├── docs/                   # 本套工程文档 + 专题文档
├── .github/workflows/ci.yml# CI：verify(四门禁) + docker + e2e
├── Dockerfile / docker-compose.yml / startup.sh / kami.config.example.json
└── .data/（运行时生成，不入库）# 一切持久化落盘根（KAMI_ROOT 解析）
```

`.data/` 运行时布局（storage.md 为官方口径）：`auth-secret.json`、`kami-db-snapshot.json`（PGlite 快照）、`lan-token.json`、`proxy.json`、`media/`（封面盘缓存）、`source/`（列表缓存）、`vault/`（vault.sqlite + files/）、`rankings/rankings.sqlite`。

## 1.5 项目依赖关系

**项目内**：`app/*（薄壳）→ src/routes/*（实现）→ src/lib/*（领域/基础设施）→ .data/ + 上游`。约束：`app/` 不写逻辑；`.server.ts` 不进客户端 bundle（命名约定 + db.ts:180-184 运行时抛错双保险，无编译期隔离）。

**模块间关键依赖链**（详见 diagrams/模块关系图.md）：

- 数据面：UI → source.ts → /api/source → source-cache → dispatch → 站点适配 → http → curl-fetch → proxy.server
- 媒体面：ProxiedImg → media-lane → /api/media → media.ts → media-cache → curl-fetch
- 同步面：AccountSyncBridge → account-sync → /api/account/sync → user_sync_segments → db-snapshot

**第三方依赖**（运行时 29 个，关键项）：next 16.3.4 / react 19.2 / better-auth 1.7.4 / @electric-sql/pglite 0.5.4 / pg 8.16 / kysely 0.28.5 / undici 8.10 / puppeteer-core 25.9 / zod 4.4 / zustand 5 / @tanstack/react-query 5.101 / tailwindcss 4.3 / fflate / gifenc。开发侧：tsgo（@typescript/native-preview）、Playwright 1.63、ESLint 9。

**外部系统依赖**：Pixiv ajax/ranking 接口（非官方）、FANBOX api.fanbox.cc、Moebooru JSON API（yande/konachan）、Danbooru JSON API（Cloudflare + Basic 认证）、SauceNAO/ascii2d/IQDB（HTML/JSON 混合）、可选 HTTP/SOCKS 代理、可选 Postgres（DATABASE_URL）。

**已知依赖风险**：`node:sqlite`（Node 22 实验性 API）、tsgo 原生预览编译器、PGlite WASM 实例强杀可能损坏目录（故纯内存 + 快照，R-11）。
