## 一句话理解这个项目

Kami 纸匣是一台**跑在自己电脑上的图站中枢**：Next.js 服务端代替浏览器访问 Pixiv / FANBOX / yande.re / Konachan / Danbooru（带代理、带三层缓存、带凭据隔离），前端只跟本站通信；看中的作品经下载队列落入「纸匣」（用户文件夹优先，应用内目录兜底），应用账号体系把设置与目录加密同步到服务端，换浏览器/设备不丢数据；未登录访客与 LAN 令牌形态各有独立访问面。
