## 一句话理解这个项目

Kami 纸匣是一台**跑在你自己电脑上的图站中枢**：Next.js 服务端代替浏览器去访问 Pixiv / FANBOX / yande.re / Konachan / Danbooru（带代理、带缓存、带凭据），前端只跟本站通信；看中的作品经由下载队列落入「纸匣」（用户文件夹优先，应用内目录兜底），应用账号体系再把设置与目录同步到服务端，换浏览器不丢数据。
