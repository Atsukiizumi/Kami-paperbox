# 时序图（Sequence Diagrams）

**图的目的**：四个需要精确到消息顺序的场景。**涉及的模块**：M1-M8。2026-09-11 复核：补数据面访问闸步骤与分段同步语义。

## 图 1：浏览请求全链（含访问闸、缓存与代理熔断）

```mermaid
sequenceDiagram
    participant P as 页面(react-query)
    participant G as withDataPlane 访问闸
    participant A as /api/source
    participant C as unstable_cache + .data/source
    participant U as upstream 适配
    participant O as outboundFetch
    participant X as 图站上游

    P->>G: POST {op, cookie, safeMode, ...}
    G->>G: Fetch-Metadata 同站校验（跨站→403）
    G->>G: 应用会话 或 LAN 令牌（无→401）
    G->>A: 放行
    A->>A: zod 校验
    alt fresh=true
        A->>C: revalidateTag(source:key)
    end
    A->>C: 读缓存
    alt 命中且未过期
        C-->>A: FetchOk
    else miss
        A->>U: dispatchFetch
        U->>U: 拼 URL+头（Referer/Basic/CSRF）+ 过滤参数
        U->>O: outboundFetch(url)
        alt 无代理
            O->>X: 原生 fetch
        else 有代理且未熔断
            O->>X: undici ProxyAgent（连接复用）
            O->>O: 失败则计数，连败3次开熔断10min
        else 熔断窗口内
            O->>X: curl 子进程（--max-time 40）
        end
        X-->>O: JSON
        O-->>U: body
        U->>U: 归一化 WorkCard[] + 三层内容过滤
        U-->>A: FetchOk
        A->>C: 写回缓存（顺手记水位）
    end
    A-->>P: 200 FetchOk
    P->>P: 合并进 queryClient（30min stale）
```

## 图 2：登录中转（puppeteer 投屏）

```mermaid
sequenceDiagram
    participant S as 设置页(session-relay)
    participant L as /api/login-browser
    participant B as browser-login.server
    participant CH as 无头 Chrome(CDP)

    S->>L: POST {site:"pixiv"}
    L->>B: startBrowserLogin
    B->>CH: 启动（临时 profile，可挂代理）
    B->>CH: goto 官方登录页
    B->>CH: Page.startScreencast
    loop 直到 done/error/4min
        CH-->>B: JPEG 帧
        B->>B: job.frame = base64
        S->>L: GET ?frame=1（280ms 轮询，需过访问闸）
        L-->>S: {status, frame, ...}（凭据只在 done 快照返回）
        S->>L: POST {action:"input", event}
        L->>B: dispatchLoginInput
        B->>CH: mouse/keyboard/insertText
        B->>CH: Network.getAllCookies（700ms 轮询）
    end
    B->>CH: goto 首页确认身份（pixiv）
    B-->>L: job={status:done, pixiv, profiles}
    L-->>S: 快照
    S->>S: applyLoginSession → store
    S->>L: POST /api/sessions
    L-->>S: Set-Cookie kami_pixiv（HttpOnly 30d）
    B->>CH: finally 关闭 + 删临时 profile
```

## 图 3：入队归档（串行队列）

```mermaid
sequenceDiagram
    participant C as 卡片/详情
    participant Q as useQueue(runQueue)
    participant A as /api/source · /api/media
    participant F as 用户文件夹(FS API)
    participant V as IDB + /api/vault

    C->>Q: enqueueWork（纸片动效）
    loop 每项（单并发，间隔400ms）
        Q->>A: POST op 详情
        A-->>Q: WorkDetail（pages）
        loop 每页
            Q->>A: GET /api/media?u=
            A-->>Q: 像素（90s 超时）
        end
        alt ugoira
            Q->>Q: zip→帧→GIF（失败存zip）
        end
        alt 文件夹可用
            Q->>F: writeRelativeFile（模板路径）
        else
            Q->>V: IDB blobs + PUT /api/vault
        end
        Q->>Q: patch 进度（progress/total）
    end
    C->>V: 封面读取：IDB 优先 miss 打 /api/vault
```

## 图 4：应用账号同步（分段推/拉 + 加密）

```mermaid
sequenceDiagram
    participant U as useSettings 等四 store
    participant BR as AccountSyncBridge
    participant SY as /api/account/sync
    participant DB as user_sync_segments(PGlite)
    participant SN as db-snapshot

    Note over BR: 登录成功（密码在手）
    BR->>SY: POST {action:"kdf-salt"}
    SY->>DB: user_sync_meta 取/建 salt
    SY-->>BR: kdfSalt
    BR->>BR: KEK=PBKDF2(密码,salt) → sessionStorage
    BR->>SY: GET（better-auth cookie）
    SY->>DB: select segments + legacy + meta
    SY-->>BR: {segments, legacy, kdfSalt}
    loop 每段（settings/vault/lexicon/history）
        alt remote.exportedAt > marker[segment]
            alt settings 段为密文且无 KEK
                BR->>BR: 跳过（本地凭据不动）
            else
                BR->>U: applySegment（写 store/IDB）
            end
        end
    end
    BR->>BR: 5s 静默窗
    Note over U: 用户改设置
    U-->>BR: subscribe 通知
    BR->>BR: 分段防抖
    BR->>SY: POST {segment, exportedAt, payload}
    Note over BR: settings 段：有 KEK→CipherBox 密文<br/>无 KEK→credsOmitted 明文偏好（且服务端已密文时跳推）
    SY->>SY: requireUserId + validateSegment（401/400）
    SY->>DB: upsert（段级 LWW）
    SY->>SN: scheduleSnapshotDump（500ms）
    SN->>SN: tmp+rename 原子写 .data 快照<br/>⚠ 不含 segments/meta（TD-19）
```

**图解与风险**：图 2 的轮询与快照均已过访问闸（SEC-02 ✅），凭据只在登录完成时刻返回给已配对客户端；图 4 已是段级 LWW + 设置段密文（TD-09/SEC-03 ✅），**剩余风险是 TD-19：快照不含分段表，PGlite 形态重启后 GET 只剩空段**；图 1 的熔断状态是进程内的，重启即清零。
