# 时序图（关键链路）

- **目的**：五条最关键链路的真实调用时序（谁调谁、返回什么、异常怎么传）。
- **基线**：`main@75e7de0`（含 bd1f28c）。

## 1. 浏览取数（缓存穿透链）

```mermaid
sequenceDiagram
  participant UI as 浏览页(infinite query)
  participant S as source.ts
  participant API as /api/source
  participant SC as source-cache
  participant D as dispatch
  participant CF as curl-fetch(池/curl)
  participant PX as Pixiv
  UI->>S: fetchSource(op)
  S->>API: POST (zod 校验后)
  API->>API: withDataPlane 闸
  API->>SC: cachedDispatchFetch
  SC->>SC: .data/source 命中? (30min)
  alt miss
    SC->>D: dispatchFetch
    D->>CF: upstreamJson (cookie/UA/Referer)
    CF->>PX: GET/POST
    PX-->>CF: JSON
    CF-->>D: 解析
    D-->>SC: FetchOk
    SC->>SC: 写盘缓存
  end
  API->>API: unstable_cache 二层 (1800s)
  API-->>S: FetchOk
  S-->>UI: WorkCard[]
  Note over API,PX: UpstreamError→502；登录/参数错误→400（S7 分类）
```

## 3. 登录中转（bd1f28c 后）

```mermaid
sequenceDiagram
  participant R as session-relay
  participant API as /api/login-browser
  participant J as browser-login.server
  participant CH as 无头 Chrome
  participant PIX as 官方登录页
  R->>API: POST {site}
  API->>J: start job (4min 超时)
  J->>CH: 启动(--no-sandbox, 用户代理)
  CH->>PIX: 打开登录页
  loop 280ms 轮询
    R->>API: GET ?frame=1
    API->>J: snapshot
    J-->>R: JPEG 帧 (凭据已剥离)
    R->>API: POST {action:"input", event}
    API->>J: CDP 转发
  end
  alt 非 2xx (含访客 401)
    API-->>R: 错误 → 立即 setJob(error)（bd1f28c 快速失败）
  else PHPSESSID 匹配登录正则
    J-->>R: done
    R->>API: GET ?credentials=1 (一次性, 内存即清)
    R->>R: applyLoginSession + syncSessions
  else 超时/cancel
    J->>J: job 清理
  end
```

## 5. 账号同步（推送/拉取，bd1f28c 后）

```mermaid
sequenceDiagram
  participant B as AccountSyncBridge
  participant AS as account-sync
  participant API as /api/account/sync
  participant DB as user_sync_segments
  participant SNAP as db-snapshot
  Note over B,AS: store 变化 → 4s 防抖
  B->>AS: pushAccountSyncSegment
  alt 有 KEK (sessionStorage)
    AS->>API: POST settings = CipherBox 密文
  else 无 KEK
    AS->>API: POST plain + credsOmitted
  end
  API->>DB: UPSERT (validateSegment)
  API->>SNAP: scheduleSnapshotDump
  Note over B,AS: 登录时拉取
  B->>AS: pullAccountSync
  AS->>API: GET (withDataPlane + requireUserId)
  API-->>AS: segments
  alt cipher + 有 KEK + 脏标记
    AS->>AS: mergeCredentialsOnPull 本地凭据保留 (bd1f28c)
    AS->>API: 补推 settings
  else cipher + 无 KEK
    AS->>AS: 跳过
  end
```
