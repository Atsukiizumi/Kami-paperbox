# 数据流图（DFD）

- **目的**：数据的源、汇、加工与存储位置（含凭据流向这一敏感面）。
- **涉及模块**：全部。
- **基线**：`main@75e7de0`。

```mermaid
flowchart LR
  U([用户交互]) --> P1((浏览/搜索<br>React Query))
  P1 -->|"POST op"| API[/api/source/]
  API --> C1[(.data/source<br>30min)]
  API --> C2[(Next<br>unstable_cache)]
  API --> P2((dispatch<br>站点适配))
  P2 -->|"undici/curl"| EXT[(图站上游)]
  P2 -->|"WorkCard[]"| P1

  P1 --> C3[(localStorage<br>browse-cache 24h)]
  P1 --> P3((榜单归档)) --> |PUT ≤200 条| C4[(.data/rankings<br>SQLite)]

  IMG[ProxiedImg] -->|"GET ?u="| MAPI[/api/media/]
  MAPI --> C5[(.data/media<br>7d·8MB)]
  MAPI --> P4((媒体代理<br>白名单/单飞/闸)) --> EXT

  P5((collectWorkFiles<br>含 GIF 合成)) --> C6[(IndexedDB<br>kami-vault)]
  P5 -->|"可选"| FS[(用户文件夹<br>FS Access)]
  P5 --> |PUT| VAPI[/api/vault/] --> C7[(.data/vault<br>SQLite+files)]

  P6((queue-runner)) -->|"fetchBlob"| MAPI
  P6 --> FS

  LOGIN((browser-login<br>无头Chrome)) -->|"一次性凭据"| SET[(localStorage<br>kami-settings)]
  SET -->|"syncSessions"| CK[HttpOnly 镜像 cookie ×3]
  SET -->|"body 随请求"| API & MAPI

  SYNC((account-sync<br>KEK 加密)) --> |"cipher 段"| SAPI[/api/account/sync/] --> C8[(user_sync_segments<br>jsonb)]
  SAPI --> SNAP[(.data/kami-db-snapshot<br>+ restore-failed)]
  AUTH((better-auth)) --> C8
  C8 --> SNAP

  WATER((cache-watermark)) -.->|"水位淘汰"| C5 & C1
```

**图解**：三条主数据流（列表、媒体、收藏）各自带多级存储；凭据流是第五条暗线——localStorage 明文（SEC-03 残余）→ 请求体 → HttpOnly 镜像 → KEK 密文段（服务端只见密文）。

**风险点**：① legacy 明文段仍可进 C8/SNAP（SEC-14）；② C5 上限 8MB 与回源 48MB 口径不一致（PER-8）；③ C4/C7 不参与水位（TD-31）；④ SNAP 多进程互踩无防护（R-12）。
