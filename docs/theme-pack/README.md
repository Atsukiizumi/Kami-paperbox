# 主题包（everything can design）

把整个主题文件夹（或 zip）丢进主题文件夹就能在 **设置 → 外观 → 主题包** 里启用（「打开主题文件夹」按钮直达；磁盘位置在数据目录 `.data/themes/`）。主题包可以改配色、外壳形态、案头布局，还能带 CSS 片段和字体/纸纹素材。

## 装一个主题

1. 设置 → 外观 → 主题包 → 点「**打开主题文件夹**」（第一次会自动生成 `_template` 样板）。
2. 把别人分享给你的**整个文件夹**或 **zip 文件**放进去。
3. 回到设置页点「**重新扫描**」（列表来自服务端缓存，改了包内文件必须点它，光刷新页面没用），列表里出现后点「**启用**」。

卸载 = 删掉那个文件夹；换主题 = 启用另一个；停用 = 回到内置观感。

## 让 AI 替你做一个（推荐给不想动手的人）

1. 打开主题文件夹，进 `_template/`，把 `agent-prompt.md` 的内容整段复制。
2. 粘贴给任意 AI（Claude / ChatGPT / Grok…），末尾补一句你想要的感觉，比如「雨夜读信的安静蓝黑」。
3. AI 会给你 `kami-theme.json`（和可选的 `theme.css`）；在 themes/ 里新建一个文件夹，把这些文件放进去。
4. 若 AI 提到要字体/纸纹图片：把文件放进该文件夹的 `assets/`，按 AI 给的说明在 `kami-theme.json` 的 `assets` 段声明。
5. 回设置页「重新扫描」→ 启用。

## 导出 / 分享你现在的观感

设置 → 外观 → 主题包 →「**导出当前为主题包**」：把现在的配色 + 外壳 + 案头摆法打包成主题文件夹里的一个新包。若当时正启用着某个主题包，包里的 CSS 与素材也会一并克隆进导出包——对方不用装原包就能还原你的完整观感（#222）。把这个文件夹整个发给别人，对方丢进自己的主题文件夹即可。

## 主题包怎么工作

- **两层合并**：你自己调过的设置 > 主题包 > 内置默认。启用主题包不会冲掉你摆好的案头——「跟随主题」两枚开关（外壳 / 案头布局）决定主题管多少；关掉就锁死自己的。你一进编排模式保存，跟随布局会自动让位给你。
- **跨设备**：设置只同步「你现在用哪个主题」；主题包本体是文件，新设备要自己拷过去。缺包时自动回默认并提示，放回去自动恢复。
- **安全**：包内容只读、无代码执行；CSS 会被清洗（禁 `@import`、`url()` 只认包内声明的素材）；单文件 ≤2MB、解压后总量 ≤32MB、zip 条目 ≤512、CSS ≤64KB、最多 50 个包。

## 常见问题对照

| 现象 | 原因与解法 |
| --- | --- |
| 列表里没有我的包 | `kami-theme.json` 坏了（JSON 注释/尾逗号/缺 `kamitheme: 1`/缺 `meta.name`）。对照 `_template` 检查；zip 的话先解压排查再压回去 |
| 包出现了但标「部分生效」 | 某段被跳过——悬停徽标看原因（如 `css 文件缺失`、`shell 形态不合法`、`url 未声明`） |
| 配色/布局没变 | 检查「跟随主题」开关；布局跟随在编排保存过之后会自动关 |
| CSS 里的图片/字体不出 | `url()` 的路径必须同时在 `assets` 段声明，且文件真的在包里 |
| 启用后另一台设备没效果 | 包不跨设备同步——把文件夹拷到那台设备的 themes/ |

## kami-theme.json 速查

字段全可选（缺哪段哪段用默认）：`meta`（名字必填）· `palette`（base 内置主题 + overrides 颜色键）· `shell`（desk/rail/zen + 白名单旋钮）· `layout`（槽模型编排）· `css`（相对路径）· `assets`（id + file）· `preview`（缩略图）。完整注释版见 `_template/agent-prompt.md`。
