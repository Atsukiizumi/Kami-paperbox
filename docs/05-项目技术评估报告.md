## 5.2 架构与模块耦合

- **BFF 单漏斗**是全项目最重要的单一决策：凭据/代理/反爬对抗收敛服务端，前端零直连——安全与性能故事都建立在其上。
- **薄壳双层路由**已被一次真实迁移（TanStack→Next）验证成本可控。
- **耦合热点**：① `src/lib` ui-support 域仍平铺 72 个实现文件（watch/masonry/tag/desk 等），横向新依赖零阻力（eslint 只拦了 server 误引与反向依赖）；② 三套存储一致性全靠应用层协议；③ 队列状态存浏览器 localStorage（重载后需重拉，设计取舍）；④ AppShell 对浏览页已 dynamic import 拆包（PER-13 ✅，#154 后对象随迁 @/routes/browse）。

## 5.5 性能评估

**已落地的性能工程**（值得记录的决策）：undici 持久连接池（单请求 1-6s → 预热 0.2-0.4s）+ 3 败熔断 curl 降级；三层读缓存（30min 内零上游）；媒体车道 4 条 + priority 插队（点击→跳转 10.7s → 0.2-0.9s）；单飞去重（键=URL+账号指纹）；瀑布流一次成版 + 骨架同算法；sweepCache 分批 yield；danbooru JSON 通道进池（A/B ~1.9x）；榜单未公布窗口 10min 短记忆；AppShell 拆包；**查重候选对生成改鸽笼分桶**（#159：dhash 均分 4 段各建索引、距离 <16 位必共享一段全等只在桶内配对，4000 条 5.5s→7ms，阈值 ≥16 位回退朴素保语义）；案头轮播全部合成层动效（rAF 只写 transform、8s 整批淡换双缓冲）。
