# 12 — 安全评估

> 基线 `main@75e7de0`（含 bd1f28c 修复，2026-09-12 全量重推导核对）。

## 12.1 威胁模型（先明确前提）

设计前提「单用户、自己机器、可信局域网」，但**默认绑 0.0.0.0:8080**（LAN 访问是特性），故模型必须覆盖「局域网内存在不可信设备」；访客层（2026-09-11）引入「应用账号开启但未登录的匿名使用者」，bd1f28c 后访客面已扩展到绑定链路。

| 资产 | 位置 | 暴露面 |
| --- | --- | --- |
| 图站会话（PHPSESSID/FANBOXSESSID/Danbooru key） | localStorage kami-settings（明文，长期残余）、请求体、HttpOnly cookie（per-browser 镜像）、user_sync.payload（**legacy 明文仍可入，SEC-14**）、备份 JSON（v2 可加密）、login-browser 内存（一次性取走） | 高 |
| 纸匣内容 | /api/vault、.data/vault | 高 |
| 出站通道 | /api/proxy（可被导向恶意代理） | 高 |
| 应用账号库 + KEK salt | PGlite/快照（restore 失败行隔离文件） | 中 |
| 上游流量 | undici/curl + 用户代理 | 中 |

## 12.2 安全问题清单

> 状态（2026-09-12，bd1f28c 后核对）：SEC-01~05/07/09/10 ✅；**SEC-11 ✅、SEC-12 ✅（bd1f28c）**；SEC-03 长期残余 = localStorage 明文（单机信任模型接受）。**SEC-14 ✅（S10~S11 批次：legacy 明文写路径 410 关闭）**；观察：SEC-06、SEC-08；SEC-15 ✅（PR #117 .dockerignore 排除）；记录性：SEC-13。
> 访客层注记（2026-09-11，bd1f28c 扩围）：访客可用的公开面 = source / social / media / reverse-search / rankings 只读，**加上绑定链路三路由（login-browser / sessions / whoami）**——依据：凭据不进轮询快照（SEC-02 剥离 + `?credentials=1` 一次性）、HttpOnly 镜像 cookie per-browser 无跨用户面、whoami 空 cookie 早退不打上游。个人面（vault 读写、account/sync）与账号关闭形态（LAN 令牌）不变。残余：匿名设备可把本服务当上游代理用（带宽/IP 消耗），个人自部署接受。
