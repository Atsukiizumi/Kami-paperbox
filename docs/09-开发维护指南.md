```bash

```

## 9.3 工程约定（摘自 AGENTS.project.md 与代码惯例）

- 文件头注释三段式：**作用 / 用法 / 为什么**（大量「为什么」注释是本仓库最重要的知识资产，例：curl-fetch.server.ts:4-9、media.ts:3-6）。
- `.server.ts` 后缀 = 服务端专属；防客户端误引靠命名 + db.ts:180-184 运行时抛错，**无编译期隔离**（无 server-only 包）。
- 数据通道铁律：下载必走 enqueueWork；Cookie 只经 browser-login 通道；真实 PHPSESSID 禁止入库。
- queryKey 纪律：身份敏感键用 `credentialTag(cookie)` 指纹；setQueryData/invalidate 的键必须与 useQuery 逐字一致（正例 work.$source.$id.tsx:148-154；反例 user.$id.tsx:109，TD-23）。
- Trellis 工作流（.trellis/）：任务 PRD/设计/实现三件套；spec 索引在 .trellis/spec/{guides,frontend}。

## 9.4 高频陷阱

| 陷阱 | 说明 |
| --- | --- |
| KAMI_ROOT | resolveKamiRoot 兜底 cwd；从任意目录起进程 `.data` 落错位置；e2e 靠仓库外临时根隔离（e2e-server.mjs） |
| masonry 常量三处 | MASONRY_MIN_COL（TS）、--masonry-min（CSS 变量）、minmax(170px,1fr) 字面量必须同步（iOS 旧 WebKit 兼容，14eb295） |
| 双层缓存 TTL | unstable_cache 1800 与 SOURCE_CACHE_TTL_MS 两处定义（TD-27），改缓存时长要一起改 |
| 缓存键参数集 | 新增过滤参数必须进 sourceCacheKey 的 payload（fanbox 缺 hideAi 是前车之鉴，TD-36） |
| 单飞 cookie | inflightMedia 绑定首调用方凭据，多凭据并发会串（TD-40） |
| Windows | scripts 直调 next JS 入口绕 cmd；改动 scripts 需三平台验证 |
| 快照 jsonb 白名单 | 新 jsonb 列名不叫 payload 会被当文本插入 |
| guests | 任何新 /api 路由都要显式决策 guest；改 guest 面必须同步 e2e/guest-tier.spec.ts |

## 9.5 代码结构速断
