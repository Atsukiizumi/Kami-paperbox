## 1. 色彩 token（双层墨：纸/案）

| Token | 纸（亮） | 案（暗） | 用途 |
|---|---|---|---|
| `--bg` | `#f3efe8` | `#0e0d0c` | 页面底 |
| `--fg` | `#141210` | `#f3efe8` | 正文/标题 |
| `--muted` | `#5e5954` | `#a39c93` | 次级文字 |
| `--line` | `rgb(fg 14%)` | `rgb(fg 14%)` | 发丝线（一切分割线/边框） |
| `--line-strong` | `rgb(fg 34%)` | `rgb(fg 32%)` | 结构线（装饰圆/折角） |
| `--paper` | `#e7dfd2` | `#1b1916` | 纸背（卡片面/图块底） |
| `--paper-2` | `#f7f3ec` | `#26231f` | 二层纸（骨架/悬浮层） |
| `--seal` | `#8f3d32` | `#e8a09a` | 印泥红（日期章/未读/收入纸匣，仅此三处） |

**朱红纪律不变**：全页只允许日期章、未读计数、「收入纸匣」三个语义位用 `--seal`。

## 2. 字体（仅两族，无 mono）

- `--serif` = `"Newsreader", "Noto Serif SC", "Songti SC", serif` — 展示标题（h1 级：`font-weight 560; letter-spacing -0.045em; line-height 0.84`）与**当前态**。
- `--sans` = `"Noto Sans SC", "Microsoft YaHei", sans-serif` — 正文与标签。
- **当前/激活态 = 衬线斜体 + fg 色**（`.modes button[aria-current="true"]` 等），不用底色药丸。
- 标签 = `--sans` 11px + `letter-spacing 0.14–0.18em`。**禁止等宽字体做标签**（批一~三的 mono 标签是偏差，校准项）。
- 大标题字距体系：`0.14 / 0.16 / 0.18 / 0.28 / 0.42em` 五档。

## 3. 线与形

- **圆角纪律：全局 0；唯一的圆 = 圆本身**（日期章 92px 正圆、装饰圆环、8px 圆点）。批一的方形日期章是偏差，校准项。
- 一切分割 = `1px solid var(--line)`；结构装饰 = `1px solid var(--line-strong)`。
- **零阴影**：全站无 box-shadow（含卡片、浮层、悬浮胶囊）。
- 视口骨架：外框 `inset 12px` 发丝框 + 左竖线 112px；左栏宽 88px。
- 浮层（笺/印）：贴右缘整高面板，纸色底 + 左边线，进出 `transform .7s var(--ease)`。

## 4. 动效

- 唯一缓动：`--ease: cubic-bezier(0.16, 1, 0.3, 1)`。
- 时长档：**0.45s**（色彩/状态）、**0.7s**（抽屉/面板）、**0.95–1.2s**（进场）。
- **进场 = clip-path 自下而上揭起**（`inset(100% 0 0 0) → inset(0)`），逐格 stagger 0.05–0.22s——批二 v2 改成的「落纸 settle 8px」是偏差，校准项（样张Scheme A 的签名动效就是帘幕揭起）。
- **hover = 变色不变位**（`background/color .45s`）；批三的卡片 translateY(-2px) 抬升是偏差，校准项。
- 关停：`html[data-motion="off"]` 下 `transition/animation: none !important`。

## 6. 红线（继承项目铁律）

- 出厂红线：默认稿纸版式零「今日的纸/日期章」文案（e2e ⑥ 守护）。
- 任何分辨率与 DPI 自适应（满宽/密度升档/零留白）。
- Avoid unnecessary secondary labels and descriptions. Let the layout do the explaining.
- 色板归主题，语法归本规范——主题只换颜色不换结构（例外：纸格 / 装帧 / 台纸三套**结构主题**经用户在 Grok 会话 01a1742d 陆续放行「框架随你动」，壳层几何各自成段，见 §8）。

## 7. 销账记录（2026-10-27）

- **印红单档制**：产品印泥红唯一 = `--seal: #8F3D32`（各主题 danger 位承接）。叙事亮红 `#C93A2B` 仅存在于 `/bindery` 演示间（该页不随产品换肤），不进入产品面。「双档」提案就此关闭。
- **装帧方案 B 的 IA 反馈归档**：用户在 Grok 会话（01a1742d）对装帧案的反馈——「浏览/历史是大量图、需要专门页面展示；画师可留右栏」——其诉求已由现状满足（`/browse` 专页 + 案头画师墙右栏/副栏位），记录为未来 IA 演进输入，不立项。
- **「右上角遮挡」定性**：顶栏自动收起（kami-chrome-down）途中半透明+backdrop-blur 叠在内容上的中间态；修复=顶栏改不透明纯色（bg-bg 去 blur），要么完整遮、要么完全走。

## 8. 台纸登记（2026-10-28 · 第三套结构主题）

第三种壳层读法，与纸格（满页的格）、装帧（案上的书）并列：**窗口是冷灰墙（`--kami-wall`：夜 `#2c2a28` / 昼 `#d4cdc2`，仅桌面书案形态生效），内容是一块四周均匀内缩 ~28px、昼夜同一套纸色不反色的裱纸（`#f6f1e8` / `#1a1814`）**。语法自成段（`styles.css` 的 `html[data-theme="mat"]` 各段）：

- **房间在纸的下沿**：九个房间横排成说明条（13px / 0.14em / 顶发丝线），**长度只到内容、居中**（美术馆标签式，不拉满板宽；窄桌面放不下时内部横滑），当前项 = 6px 实心方印 + 衬线（不斜体、无朱红下划线）——当前态语言与纸格（衬线斜体）、装帧（衬线+订线）区分。
- **顶栏「从独立到融入」**：顶栏是纸头上的一条（absolute 贴板顶，非 fixed 悬浮）——页顶时是带下缘发丝线的独立横条，一滚动就**随纸滚离视口**，内容接管版面，永不与内容重叠。
- 顶栏只留右上四件（图源 / 遮盖 / 主题名 / 账号），无徽章无圆头像；无侧栏、无订口；编排条贴板下沿（骑在说明条上方）。
- 内容：标题 28–40px 目录号读法（上行 0.18em 目录号小字）；图卡宽边裱框（图四周留纸边）、图注居中；AI 图注牌贴图下沿居中（角标簇与尺寸牌不动）；队列行式无订线；设置居中说明牌。
- 作品/详情页的出血条（`.kami-detail-nav` / `.kami-work-sticky` / `.kami-work-stage` 的 `-mx-10`）按台纸页框 1.75rem 重配负边距——**任何元素不得越过纸边压到墙上**。
- **作品页操作条同款「从独立到融入」**：页顶是纸带（底色+发丝线+毛玻璃）；滚过 100px 条身转透明——只剩左（上一页/返回浏览）右（纸匣/下载等）两组按钮浮在纸上，回顶复原。状态由组件打 `data-dissolved`（滚动驱动 CSS 动画在作品页与 body 滚动锁组合下不可靠，弃用）。
- 强调色是墨不是朱红；朱红仍只给日期印、未读、「收入纸匣」三处（队列/追踪数字走 danger）。
- 移动端与其余桌面形态保持标准壳 + 台纸色板，不出现墙与下沿条。
